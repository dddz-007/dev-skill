# dev-skill

`dev-skill` 是面向所有项目的全局通用全栈开发技能，不绑定项目路径、技术栈、数据库或部署平台。它覆盖完整功能、已有功能修改、单独前端/后端/数据库任务、问题修复、代码审查、数据库脚本、联调和发布前检查。

## 快速调用

- Cursor：`/dev-skill`
- Codex：`$dev-skill`
- Qoder：若支持技能命令，使用 `/dev-skill`；否则读取 `SKILL.md`。

首次使用建议说：“先调查和制定方案，不要立即修改代码或数据库。”数据库授权未填写时默认只读。

## 安装

把整个 `dev-skill` 目录复制到对应产品的全局技能目录；不要复制到某个项目目录后误当成全局技能。不同产品版本的目录可能不同，以产品设置为准。

参考 `examples/使用案例.md` 获取各场景的可复制调用文本。

## 安全

不要把密码、令牌、Cookie、私钥或生产连接串保存到本目录、技能文件、规则文件或版本库。

## 能力边界

技能不能保证任意模型在任意环境中必然完成需求。项目不可运行、权限不足、资料缺失或测试不可用时，Agent 必须如实标记未验证或被阻塞，而不是编造完成。
